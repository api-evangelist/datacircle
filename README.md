# Datacircle

This profile has been removed at the request of its owner.

On 2026-10-19, waynehamadi, the owner of Datacircle, asked in
[issue #1](https://github.com/api-evangelist/datacircle/issues/1) for the APIs.io profile and this
repository to be taken down: the Datacircle API has been closed, so its MCP server and plugins no
longer work. The request was honored in full.

- Every artifact, specification and the `apis.yml` index have been removed, and this repository's
  history has been reduced to this notice.
- The provider, API and artifact pages on [APIs.io](https://apis.io) and the profile on
  [API Evangelist](https://apievangelist.com) have been removed. Datacircle is not rated.
- Datacircle is on the API Evangelist delisting registry, so no pipeline will re-add it.

For removal requests or questions, contact info@apievangelist.com.
